# MyNotes

A simple notes app built with React.

MyNotes allows you to create, save, and delete notes. Notes are stored in the browser using localStorage, so they remain available after refreshing the page.

## Features

- Create notes with a title and description
- Form validation
- Delete notes
- Save notes using localStorage
- Responsive design
- Simple and clean interface

## Built With

- React
- Vite
- CSS
- React Icons
- Browser localStorage

## Getting Started

### Clone the repository

git clone https://github.com/oeprxc/my-notes-app.git

### Install dependencies

npm install

### Start the development server

npm run dev
